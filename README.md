## Прогресс обучения

### Day 01: Основы
- [x] Установка Python и VS Code.
- [x] Функции `print()` и `input()`.
- [x] Переменные и конкатенация строк через `+`.

### Day 02: Числа и вывод
- [x] Параметры функции `print()`: `sep` и `end`.
- [x] Соблюдение стандарта PEP 8 (пробелы вокруг операторов).
- [x] Преобразование типов: `int()` и `str()`.
- [x] Арифметические операторы: `+`, `-`, `*`, `/`, `//` (целочисленное деление), `%` (остаток от деления), `**` (возведение в степень).
- [x] Извлечение цифр из числа с помощью математики.
- **Практика:**
  - Целочисленный калькулятор.
  - Конвертер времени (перевод секунд в часы, минуты и секунды).
  - Вычисление суммы цифр трехзначного числа.
